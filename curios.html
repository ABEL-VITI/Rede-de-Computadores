Router

Encaminhas os dados entre redes para internet.

Switch

Conecta vários dispositivos na mesma rede local.

Access Point

Cria uma rede sem fio (Wi-Fi).

Modem

Converte o sinal do provedor para rede local.

Servidor

Fornece serviços e recursos para outros dispositivos.

Placa de Rede

Permite que o dispositivo se conecta a rede.
